# 图片资产处理流水线

来源：`MCP协议/slide33.html`

这是一个“图片集合状态变化”模板，适合展示一批视觉资产如何经过条件筛选、统一处理、整理和交付。常见场景包括：媒体素材预处理、批量图片转换、内容审核后的资产归档、截图筛选与上传、数据集样本清洗。

页面有 5 个可控状态：

1. 图片池：展示混合输入资产。
2. 筛选：弱化非目标图片，突出满足条件的图片。
3. 处理：目标图片显示统一处理标记。
4. 整理：目标图片聚合成待交付集合。
5. 交付：集合连接到存储端并显示成功结果。

`sourceImages[].target` 只表示示例中的筛选结果，不应暴露为固定的横图/竖图规则。输入池支持 4～10 张图片，其中目标项最多 6 张；更多结果应分组或拆页。服务端渲染时可替换为尺寸、格式、标签、审核状态或内容类别等条件。`transformLabel`、`destination` 和 `destinationUrl` 都是可替换槽位；课程专属水印和业务域名不属于模板规则。

本目录的图片只用于视觉预览，正式 LectureAI 模板应由服务端注入受控的图片 URL 或资源引用。所有图片支持点击放大，最后一步完成后交还宿主演示器的翻页控制。
