# 图片注意力聚焦图

来源：`AI大模型原理_安恒/slide22.html` + `slide23.html`

这两个来源页可以合并成一个单页模板。它的通用结构是：

1. 展示一组候选图片；
2. 引入一个查询目标（Query）；
3. 展示图片的匹配标签（Key）和权重；
4. 聚焦高权重图片，并把它提取为 Value 进行内容解释。

它不只适合注意力机制，也可用于：

- 图片检索与相似度匹配；
- 多个证据中的重点证据筛选；
- 推荐系统的候选项排序；
- OCR / 图像理解中的区域关注；
- “相关性越高，贡献越大”的视觉化解释。

模板规则不固定具体人物、课程或图片。`assets/` 中的图片是从来源页复制的本地预览样例，只用于确认构图和聚焦效果；服务端正式渲染时必须通过图片槽位替换，不能把这些样例图片作为模板规则的一部分。
