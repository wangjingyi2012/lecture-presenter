# 页面资产普查

本目录用于从已有 PPTE 课件中发现可复用的版式族、变体、组件和风格样本。原始课件只读，不在普查过程中修改。

## 查看总览

直接打开 `gallery.html`。总览包含 138 页缩略图，并支持：

- 按课件、交互、图片、表格和代码筛选；
- 按标题、文件名和结构标签搜索；
- 标记“喜欢 / 一般 / 不喜欢”；
- 将评价导出为 `PPTE页面评价.json`。

评价保存在浏览器本地存储中。点击“导出评价”后，把导出的 JSON 放回本目录，后续即可将用户审美偏好与结构分类合并分析。

## 文件说明

- `资产普查报告.md`：人工复核后的结论和候选优先级；
- `评价合并报告.md`：将 138 页人工评价合并后的偏好结论与第一批模板优先级；
- `候选分类.json`：模板族、变体、组件和风格样本的结构化清单；
- `verify-first-batch.js`：第一批模板的浏览器截图与运行时边界检查；
- `verify-basic-templates.js`：六类基础正文模板的 1920×1080 截图与上限压力检查；
- `gallery.html`：可筛选、可评价的缩略图总览；
- `output/audit.json`：逐页原始结构指纹；
- `output/pages.json`：总览使用的扁平页面数据；
- `output/screenshots/`：138 张逐页截图；
- `output/contact-sheets/`：按课件生成的联系表；
- `audit-slides.js`、`build-gallery.js`、`build-contact-sheets.py`：可重复执行的普查工具。

“结构分”只表示页面中图片、图形、布局和交互信号的丰富程度，不是审美评分，也不直接决定模板优先级。
