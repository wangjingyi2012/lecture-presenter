# 术语展开讲解页

来源：`MCP协议/slide31.html`

这是一个“概念揭示”模板，不是固定的 CLI 页面。它把一个缩写或术语拆成三个层次：

1. 紧凑显示缩写或关键词；
2. 点击后展开完整名称，并显示一句定义；
3. 如果内容确实有可执行示例，再显示一个可选示例区。

## 示例区是可选的

`example` 槽位可以为 `none` 或直接省略。当前预览使用 `terminal` 变体，是因为来源页需要用 `grep` 命令把 CLI 的概念落到实际操作上；这不意味着所有术语页都需要终端。

未来可扩展为：

- `code`：代码片段或 API 调用；
- `process`：三步以内的使用流程；
- `none`：只讲全称和定义。

服务端选择示例变体，客户端只接收最终渲染页面。
