# AI 助手斜杠命令

工作台 AI 助手支持可发现、可复检的斜杠命令。输入 `/` 会打开命令菜单；`↑`、`↓` 选择，`Enter` 或 `Tab` 补全。

## 使用方式

- `/font-check`：检查整套课件的实际字号、字号单位和投影可读性，自动修复后复检
- `@3 /font-check`：只检查并修改第 3 页
- `/layout-check`：根据并列、对比、流程和因果关系优化布局，同时检查密度、卡片空白和投影可读性
- `/overflow-check`：检查真实渲染后的画布越界、内容区溢出和隐藏裁切
- `/density-check`：检查页面过空、卡片过高和无效留白
- `/card-check`：检查卡片空白、侧边彩条、渐变和过度卡片化
- `/copy-check`：检查讲师口吻、提问式标题、冗长屏显文案
- `/student-copy`：把页面改成简短、直白、可记忆的学员屏显文案
- `/concept-animate 概念或要求`：自动读取目标页、相邻页和现有 CSS，套用标准分步讲解骨架；一次点击只推进一个概念，也可显式写 `@页码`
- `/quality-check`：综合执行字体、溢出、密度、卡片和文案检查
- `/help`：在工作台内显示帮助

## 执行模型

命令不是提示词别名。每次任务都遵循固定闭环：

1. `inspect_slides` 在 1920×1080 隐藏画布渲染目标页面，读取计算字号和几何尺寸，并结合现有 `ppte_lint` 静态规则输出结构化问题。
2. AI 读取检查结果，只修改命令限定范围内的页面。
3. 页面写入仍经过编辑器的冲突检测和原子保存逻辑。
4. 只要发生修改，命令状态立即失效；AI 必须再次运行同类检查，结果通过后才能结束。

`/concept-animate` 使用专门的 `concept-animation` 检查。除字体、溢出和学员文案外，还会检查：3-6 个步骤、稳定主画布、两行步骤按钮、右下进度点、点击和键盘前进/回退、末步放行宿主翻页、`prefers-reduced-motion`，以及禁止自动播放和无限循环。

带 `@页码` 的命令有硬范围门禁：不能写入其他页面，也不能插页或重排整套课件。

## 扩展命令

命令注册表位于 `lecture-app/src/js/ppte-slash-commands.js`。普通命令包含：

- `name`：斜杠后的英文名
- `title`、`description`：菜单和帮助文本
- `check`：映射到 `inspect_slides` 的检查类别
- `defaultScope`：`deck` 或 `current`
- `workflow`：该命令的修复策略与禁止事项

如果新命令可复用现有检查类别，只需增加注册项并补解析测试。如果需要新的确定性判断，再在 `PpteWorkbenchAgent._collectSlideInspection` 中增加对应类别，并同步工具协议与测试。
